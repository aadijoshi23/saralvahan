# SaralVahan

SaralVahan is a mobile-first citizen-facing prototype designed to make the Indian driving licence renewal process easier to understand.

This first screen introduces the renewal journey and clearly communicates that all government services and personal data are simulated.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Production build

```bash
npm run build
npm start
```

## Scope

This prototype does not connect to government systems and does not include authentication, payments, OTP, databases, or external APIs.
